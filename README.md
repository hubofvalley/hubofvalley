Grand Valley is an independent validator and open-source infrastructure operator supporting networks across mainnet and testnet.

---

## What Grand Valley Does

- Operates validator infrastructure across supported networks.
- Publishes practical guides for node operators and ecosystem participants.
- Builds open-source tools that make node operations easier to understand and manage.
- Supports decentralised networks through technical education, useful infrastructure, and community participation.
